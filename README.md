# Retail Sales Performance Analysis Dashboard

## Project Overview

This project analyzes retail sales performance using SQL and Power BI. The dashboard provides insights into sales trends, product category performance, and customer demographics.

## Business Questions

1. How did sales perform throughout the year?
2. Which product categories generated the most revenue?
3. Which age groups generated the most revenue?
4. Which gender generated the most revenue?
5. Which months performed best and worst?

## Tools Used

* SQL Server
* Power BI
* Excel

## Key Insights

* Sales peaked in May and reached the lowest point in September.
* Electronics generated the highest revenue among all product categories.
* Female customers contributed the highest revenue.
* Customers aged 46–55 generated the highest revenue.
